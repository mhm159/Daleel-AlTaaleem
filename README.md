# Learning Guide Schools — موقع المدرسة الخاص

موقع ويب متكامل ومتجاوب للمدرسة، مبني بـ **Next.js (Frontend)** + **Node.js/Express (Backend)** + **SQLite (Database)**.

## 🚀 التشغيل السريع

**الطريقة الأسهل:** انقر مزدوجاً على `start.bat` في جذر المشروع.
- يثبّت الحزم تلقائياً عند أول تشغيل
- يشغّل الباك-إند (المنفذ 5000) والفرونت-إند (المنفذ 3000)
- يفتح المتصفح على `http://localhost:3000`
- **للإيقاف:** اضغط أي مفتاح في نافذة التشغيل → يُغلق السيرفران معاً

## 🗂️ بنية المشروع

```
school-page/
├── start.bat              # ملف التشغيل بنقرة واحدة
├── backend/               # خادم API (Express + SQLite)
│   ├── src/
│   │   ├── db/            # طبقة قاعدة البيانات (SQLite repositories)
│   │   ├── controllers/   # منطق المعالجة
│   │   ├── routes/        # مسارات API
│   │   ├── middleware/    # المصادقة (JWT)
│   │   ├── utils/         # seed + أدوات
│   │   └── server.js      # نقطة الدخول
│   └── database.sqlite    # قاعدة البيانات (تُنشأ تلقائياً)
└── frontend/              # واجهة Next.js
    └── src/app/           # الصفحات (Home, About, Admissions, Academics, News, Portal, Contact, Admin)
```

## ✨ المميزات

- **الصفحة الرئيسية:** هيرو تفاعلي، رؤية المدرسة، آخر الأخبار، الوصول السريع
- **من أنا:** رسالة المدير، التاريخ، القيم، المرافق
- **القبول:** نموذج طلب متعدد الخطوات + رسوم دراسية + دفع عبر Stripe
- **أكاديميكس:** المنهج، المراحل الدراسية، التقويم المدرسي
- **بوابة أولياء الأمور:** تسجيل دخول، لوحة تحكم، حضور، درجات، رسائل، مدفوعات
- **الأخبار والوسائط:** مقالات + معرض صور وفيديو
- **تواصل معنا:** خريطة Google + نموذج تواصل
- **لوحة الإدارة (CMS):** إدارة الأخبار، الأحداث، التقويم، القبول، الطلاب، المدفوعات، الرسائل

## 🎨 الهوية البصرية

الألوان مستوحاة من شعار المدرسة (منزل + نباتات تنمو):
- **سماوي فاتح** `#0ea5e9` — الأمان والآفاق الواسعة
- **أخضر** `#22c55e` — النمو والطبيعة
- **ذهبي/أصفر** `#f59e0b` — التميز والقيمة

## 💳 الدفع

يدعم Stripe عبر متغير البيئة `STRIPE_SECRET_KEY`. في وضع العرض (بدون مفتاح)، تُحاكى عملية الدفع بنجاح فوري بدون خصم حقيقي.

## 🛠️ التطوير اليدوي

```bash
# الباك-إند
cd backend && npm install && npm run dev

# الفرونت-إند (في طرفية أخرى)
cd frontend && npm install && npm run dev
```
